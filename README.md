# 안콘텐츠 랩 (AHN CONTENTS LaB) 웹사이트

아임웹으로 만들었던 사이트를 정적 HTML로 재구성한 버전입니다. GitHub Pages로 바로 배포할 수 있습니다.

## 페이지 구성 (실제 메뉴 그대로)

- index.html — 홈
- about.html — ABOUT US
- history.html — 공연 이력 (History) · 원본 이미지 반영
- press.html — Press
- acl-project.html — ACL PROJECT · 원본 이미지 반영
- orchestra.html — ORCHESTRA
- acl-philharmonic.html / odyssey-symphony.html — 오케스트라 하위
- gallery.html — GALLERY
- playlist.html / immersion.html — PLAYLIST · 공연 영상(YouTube) 반영
- notice.html — NOTICE

상단 메뉴는 전 페이지 동일, 모든 내부 링크는 실제 파일과 연결됨.


## 이미지
모든 이미지는 `images/` 폴더에 **원본 그대로** 저장되어 있으며, 각 페이지는 이 로컬 파일을 참조합니다.
아임웹 서버에 의존하지 않으므로, **아임웹을 해지해도 사이트가 정상 작동**합니다.
